\begin{frame}{A label-free query-profile gate: the idea}
\begin{itemize}
\item The class word's attention also fires on pixels that are not the object.
\item From unlabeled generations, learn per class where the word attends when the class is present and when it is absent.
\item At test time, down-weight pixels that look like false firings, then run the unchanged pipeline.
\item BRACE stays frozen; everything here is exploratory.
\end{itemize}
\src{runs/28--30 (F)}
\end{frame}
