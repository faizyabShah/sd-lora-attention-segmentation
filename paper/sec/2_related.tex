\section{Related work}
\label{sec:related}
\paragraph{Attention-based segmentation.}
DAAM aggregates diffusion CA to attribute image regions to prompt words~\cite{tang2023daam}. OVAM introduces a separate attribution prompt, allowing a queried word that need not occur in the generation prompt, and evaluates attention-based pseudo-masks with SA and DenseCRF post-processing~\cite{marcosmanchon2024ovam}. Our target remains the queried class word throughout. We study which available attention observations to aggregate and how to propagate the resulting seed, using the same two generated benchmark families.

\paragraph{Spatial propagation and refinement.}
SA defines an affinity between latent image positions. Repeated application of a row-stochastic affinity spreads a CA seed and can fill missing object pixels, but can also cross an object boundary. We therefore evaluate pass count, SA scale and temporal window together with the final mask. DenseCRF uses image appearance to refine boundaries~\cite{krahenbuhl2011crf}; we retain the fixed OVAM parameterization. Recent training-free diffusion segmentation work also studies attention structure and geometry~\cite{meng2026making,pei2026pearl}. NERVE combines semantic-output head weighting, local affinity, and a stopped random walk in a CLIP--diffusion setting~\cite{mahatha2025nerve}; our separate SG29 follow-up tests adaptations to a single class-word seed and the original SD softmax SA. Our later CA weighting and multiscale experiments are reported as follow-up studies rather than substituted for the confirmed pipeline.

\paragraph{Optimized tokens.}
OVAM also learns attribution tokens from annotated support images~\cite{marcosmanchon2024ovam}. A separate experiment in this repository reaches higher scores with those released tokens, but that uses mask supervision. This paper's main method and comparison use ordinary class words; optimized-token results appear only as a distinct analysis, never as training-free evidence.
