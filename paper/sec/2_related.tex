\section{Related work}
\label{sec:related}
\paragraph{Attention-based segmentation.}
DAAM aggregates diffusion CA to attribute image regions to prompt words~\cite{tang2023daam}. OVAM introduces a separate attribution prompt, allowing a queried word that need not occur in the generation prompt, and evaluates attention-based pseudo-masks with SA and DenseCRF post-processing~\cite{marcosmanchon2024ovam}. Our target remains the queried class word throughout. We study which available attention observations to aggregate and how to propagate the resulting seed, using the same two generated benchmark families.

\paragraph{Spatial propagation and refinement.}
SA defines an affinity between latent image positions. Repeated application of a row-stochastic affinity spreads a CA seed and can fill missing object pixels, but can also cross an object boundary. We therefore evaluate pass count, SA scale and temporal window together with the final mask. DenseCRF uses image appearance to refine boundaries~\cite{krahenbuhl2011crf}; we retain the fixed OVAM parameterization. Recent training-free diffusion segmentation work also studies attention structure and geometry~\cite{meng2026making,pei2026pearl}. NERVE combines semantic-output head weighting, local affinity, and a stopped random walk in a CLIP--diffusion setting~\cite{mahatha2025nerve}; our separate SG29 follow-up tests adaptations to a single class-word seed and the original SD softmax SA. SPARK sharpens diffusion-derived affinity through expansion, inflation, pruning, and normalization for unsupervised segmentation~\cite{mahatha2026spark}; our SG30 follow-up isolates these graph operations while retaining a class-word CA seed. SeeDiff iteratively extracts new seeds between SA scales and refines foreground with propagated background evidence~\cite{park2025seediff}; our SG31 follow-up tests these mechanisms using the frozen class-word CA source. These follow-ups are not substituted for the confirmed pipeline.

\paragraph{Hierarchical residuals and Markov reachability.}
FA-Seg combines refinement from several SA resolutions using fixed weights~\cite{che2025faseg}. M2N2 views SA as a Markov transition, uses first-arrival time as a spatial signal, and tests temperature sharpening and iterative proportional fitting~\cite{karmann2025m2n2}. Our SG33 follow-up retains the sequential coarse-to-fine hierarchy: earlier states enter only as residual support, and class-seeded Markov reachability replaces only its coarse initialization. Neither branch reproduces the cited method; both remain experiments until the frozen VOC selection and COCO transfer are complete.

\paragraph{Optimized tokens.}
OVAM also learns attribution tokens from annotated support images~\cite{marcosmanchon2024ovam}. A separate experiment in this repository reaches higher scores with those released tokens, but that uses mask supervision. This paper's main method and comparison use ordinary class words; optimized-token results appear only as a distinct analysis, never as training-free evidence.
