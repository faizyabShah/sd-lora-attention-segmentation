\section{Method}
\label{sec:method}
\paragraph{Semantic seed.}
For an image generated by Stable Diffusion 1.5 and target class word $w$, we query the text encoder with a separate attribution prompt, including every tokenizer piece of $w$. At each denoising call, CA module and head, the conditional image-query/text-key softmax yields a spatial token map. We average the word-piece maps and selected observations after bilinear resizing to $64\times64$. The selected CA set uses all 31 recorded calls, all eight heads and eleven modules at resolutions 8, 16 and 64; it excludes the five 32-pixel modules. The aggregate is normalized per image to $[0,1]$ to form $c$. This class-word seed requires no learned token.

\paragraph{Observation-wise propagation.}
For SA observation $i=(t,h)$ in the last 64-pixel module, let $A_i\in\mathbb{R}^{4096\times4096}$ be its row-stochastic query--key affinity. One and two passes are
\begin{equation}
 p_1=\frac{1}{|\mathcal I|}\sum_{i\in\mathcal I}A_ic,
 \qquad p_2=\frac{1}{|\mathcal I|}\sum_{i\in\mathcal I}A_i^2c.
 \label{eq:propagation}
\end{equation}
The square is taken within each observation before averaging; $\left(\frac1{|\mathcal I|}\sum_i A_i\right)^2c$ is a different operator. All SA heads are retained. The confirmed system uses all 31 calls; a later joint study selects calls 10--20, inclusive, with the rest unchanged.

\paragraph{Mask and boundary refinement.}
We min--max normalize the propagated map, upsample it bilinearly to annotation resolution, and threshold it with a threshold selected on VOC training folds. The fixed OVAM DenseCRF implementation then takes this binary prior and the generated RGB image; we do not tune its parameters on COCO-Cap. We call this refinement R2. No ground-truth mask enters map extraction, propagation or inference.

\paragraph{Exploratory CA weighting.}
A later study weights CA modules using a comparison between within-module query/key affinities and a paired SA affinity. Its A3 variant uses a transposed resized SA affinity in the implemented similarity score. We report exactly this implemented operator and its measured output; it is not an exact implementation of the published GoCA score~\cite{meng2026making}. Its selection and software-audit status are given separately in Sec.~\ref{sec:transfer} and Sec.~\ref{sec:discussion}.
