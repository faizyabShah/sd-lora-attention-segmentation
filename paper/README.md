## Current narrative draft (26 October 2026)

The main paper now tells the class-word, training-free progression: CA seed
selection, one fine SA module, two observation-wise passes, fixed DenseCRF,
then joint temporal selection after refinement. The confirmed all-call system
is 0.813 VOC-Sim OOF / 0.637 frozen COCO-Cap; SG22's later middle-call choice
is 0.816 OOF of the selection path (0.817 forced) / 0.644. SG24 A3 and its descendants are labelled exploratory:
the registered multi-candidate selector did not promote A3, and the
implemented similarity uses a transposed resized SA affinity. SG24-B and SG25–SG28 appear only as unpromoted
transfer observations; SG29 is named as running.

The final manuscript table transcribes the **class-word rows of OVAM Table 1**
from the [CVPR 2024 paper](https://openaccess.thecvf.com/content/CVPR2024/html/Marcos-Manchon_Open-Vocabulary_Attention_Maps_with_Token_Optimization_for_Semantic_Segmentation_in_CVPR_2024_paper.html).
Those published baselines use their original renders/annotations; ours uses
regenerated images. Do not silently replace that table with locally re-scored
released-mask values or call its cross-block differences paired estimates.

## Build

```bash
cd paper
pdflatex attention_segmentation && bibtex attention_segmentation \
  && pdflatex attention_segmentation && pdflatex attention_segmentation
# or: latexmk -pdf attention_segmentation.tex   (Overleaf does this)
# supplementary: the same with supplementary.tex
```

Regenerate the tables first: `python scripts/paper/export_paper_artifacts.py`
from the repository root.

The two current main-text tables are authored directly in
`sec/7_fusion.tex` (same-run SG22 nested steps) and `sec/8_transfer.tex`
(published OVAM Table 1 alongside clearly marked regenerated-image scores).
The generated tables below remain archived for the older draft and supplement.

The cluster has TeX Live 2018. The preamble therefore avoids `siunitx` and
`cuted` (use `figure*` for wide figures). The kit also needs `cleveref`,
`silence` and `multirow`, which the cluster lacks; install them from CTAN into
`~/texmf/tex/latex/` (as for the first build) or build on Overleaf.
