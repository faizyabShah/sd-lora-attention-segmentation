# sd-lora-attention-segmentation

Repository scaffold for LoRA-based Stable Diffusion training, generation, evaluation, and attention-driven segmentation workflows.

## Structure

- `configs/`: training, generation, and evaluation config files
- `data/`: raw, processed, and caption artifacts
- `src/`: core Python packages and modules
- `scripts/`: runnable helper scripts
- `outputs/`: generated images, logs, and metrics
- `notebooks/`: experimentation notebooks
