# Class competition for the A3 seed on real VOC photos (exploratory)

Every word's A3 seed comes from a fresh frozen-pipeline run on the photo's DDIM trajectory (empty-prompt inversion, so the trajectory is the same for every word); the propagation graphs are the target run's own SA. Variants: **base** = the target's A3; **joint** = A3 of the target inside one prompt listing all 20 VOC classes (shared CA softmax); `marg1` = s − max_c, `marg.5` = s − ½·max_c (clipped at 0), `rsum` = s·s/(s+Σc), `rmax` = s·s/(s+max_c); normalisation `mm` = per-word min-max, `raw` = CA probability; competitor set `voc` = the other 19 VOC classes (fixed vocabulary), `gen` = 8 generic non-VOC words (wall, floor, ground, sky, grass, tree, building, road), `top3` = the 3 VOC words with the highest raw seed peak in this photo (label-free). Competition only ever lowers the target seed. Class-macro mIoU, τ grid 0.30–0.90 (CRF every 0.05), OOF τ over 5 grouped folds. Selection rule fixed before seeing results: the competition variant with the best D OOF mIoU on C16; S is scored once with that variant.
