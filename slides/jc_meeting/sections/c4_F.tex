\begin{frame}{Comment 4: reading and possible actions}
\begin{itemize}
  \item \textbf{Reading.} The token gives a much better seed ($+0.18$ on both benchmarks). Propagation then adds less, and on COCO-Cap the hierarchy lowers the token result.
  \item \textbf{Consequence.} The contribution is not independent of how the query is obtained. It is strongest when the seed is weak (class word).
  \item \textbf{Action A (recommended).} Report the token block as a separate few-shot table and state this limit in the text.
  \item \textbf{Action B.} Keep the claim to the training-free setting and cite the token block only in the supplementary.
  \item \textbf{Action C.} Investigate the COCO-Cap drop first: it is concentrated in a few classes (sofa 0.70 to 0.34, car 0.76 to 0.66; person rises 0.28 to 0.62).
\end{itemize}
