\begin{frame}{Comment 3: caveats and possible actions}
\status{planned}
\begin{itemize}
\item BRACE reads attention during generation, so it regenerates each image; the other methods segment the stored image (difference under one grey level on most images; every sign holds on the closest subset).
\item DiffSegmenter's own evaluation tunes its background score on the test set, so it has no fair ``own rule'' row.
\item No published paper reports VOC-Sim or COCO-Cap for these methods; the old Table 5 rows are OVAM's reruns.
\item \textbf{Recommended:} main table with two paired blocks (diffusion only; with an extra model), published rows marked unpaired.
\item To decide with JC: which blocks go in the main paper.
\end{itemize}
