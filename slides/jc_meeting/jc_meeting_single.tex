\begin{frame}{1. Our gains show in clutter, but we selected on simple scenes}
\begin{itemize}
\item Most of our components barely change VOC-Sim (one object per image) and help on COCO-Cap (cluttered scenes).
\item Our selection rule used VOC-Sim only, so it could not see these gains: it kept fine-only, and we adopted the hierarchy after seeing COCO-Cap.
\item \textbf{Proposal:} change the selection set. Select on 50\% of VOC-Sim and 50\% of COCO-Cap images (split by class), and report every number on the other half of each.
\item The test halves are then untouched by selection, and the rule can see clutter.
\item We can then show final numbers on each dataset.
\end{itemize}
\end{frame}

\section{Exploring}
\begin{frame}{Exploring: a training-free query-profile gate}
\begin{itemize}
\item The class word's attention also fires on pixels that are not the object.
\item From unlabeled generations, per class and layer: the mean query where the word attends on images \emph{of} the class, and where it attends when the class is \emph{absent} (caption does not mention it).
\item At test time, each pixel's query is compared with the two profiles; a soft gate down-weights pixels that look like false firings. Then the unchanged pipeline.
\item Label-free; BRACE stays frozen. All results here are exploratory.
\end{itemize}
\end{frame}
